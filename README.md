# C&C - Soluções Digitais

Site institucional da C&C - Soluções Digitais, especializada em desenvolvimento de sites personalizados.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- TailwindCSS

## 📦 Instalação

1. Clone este repositório:
```bash
git clone https://seu-repositorio/cc-solucoes-digitais.git
cd cc-solucoes-digitais
```

2. Abra o arquivo `index.html` em seu navegador

## 🔧 Desenvolvimento

Para desenvolver, você precisará apenas de um editor de código e um navegador web moderno.
